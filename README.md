# پیام‌رسان آریا | Arya Messenger

پروتوتایپ پیام‌رسان مدرن با امکانات کانال، تیک تأیید (آبی و رنگی) و نمای ابری.

## ویژگی‌ها
- صفحه ثبت‌نام با شماره موبایل
- چت فردی و گروهی
- کانال‌ها با امکان تیک تأیید (آبی / رنگی)
- پنل ادمین برای مدیریت تیک‌ها و پاک کردن کاربران (در حالت دمو)
- طراحی مدرن و پشتیبانی فارسی

## توجه مهم
این یک **پروتوتایپ فرانت‌اند** است. پیام‌رسانی واقعی که بتواند به همه جهان پیام بفرستد، نیاز به:
- سرور و دیتابیس (مثلاً Firebase / Supabase / سرور خودتان)
- سیستم تأیید شماره (SMS Gateway)
- WebSocket یا Realtime برای پیام‌رسانی لحظه‌ای
- دامنه و هزینه ماهانه

در حالت حاضر از `localStorage` برای ذخیره‌سازی دیتاهای دمو استفاده شده.

## نحوه اجرا
1. ریپازیتوری را کلون کنید
2. فایل `index.html` را در مرورگر باز کنید
3. یا از GitHub Pages استفاده کنید

## پنل ادمین
صازنده می‌تواند با ورود به عنوان ادمین، تیک تأیید کانال‌ها را مدیریت کند و داده‌های دمو را پاک کند.
